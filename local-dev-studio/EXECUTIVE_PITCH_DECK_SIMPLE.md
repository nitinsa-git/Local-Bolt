# VibeForge — Executive & Non-Technical Pitch Deck

> [!IMPORTANT]
> **In Plain English**: **VibeForge** is a private, all-in-one "AI Software Studio" that runs right on your own computer or company server. You simply describe any app, interactive studio, or business dashboard in everyday language, and VibeForge's upgraded **Built-In Local AI Model (`Qwen 2.5 Coder 7B`)** reads your exact instructions, applies your workspace's **Selected Expert Skills**, writes the code, tests it, fixes any mistakes automatically, and shows you the live working product—without ever sending your private data to the cloud.

### ⚡ Core Technologies at a Glance (One-Line Plain-English Guide)

| Technology / Component | What It Is Used For (In One Simple Line) |
| :--- | :--- |
| **Bundled `llama.cpp` + `Qwen 2.5 Coder 7B`** *(Built-In Local LLM)* | A powerful `7.61-Billion` parameter AI coding brain included inside VibeForge (`127.0.0.1:8080`) that reads your exact prompt and builds custom apps offline. |
| **Ollama & LM Studio** *(Plug-and-Play Local LLMs)* | Lets you optionally connect additional local AI models (`Llama 3`, `Qwen 2.5 32B`, `DeepSeek`) on your machine with zero configuration. |
| **OpenAI (`GPT-4o`) & Google (`Gemini 2.0`)** *(Optional Cloud AI)* | Lets teams optionally plug in commercial cloud AI keys whenever extra cloud reasoning power is desired. |
| **Domain-Smart AI Engine** *(Context-Aware Builder)* | Knows the difference between a design/animation studio and a business data dashboard—so follow-up requests always match your project's exact context. |
| **5-Tab Code & Library Generator** *(Built-In Code Exporter)* | Generates ready-to-copy code in **HTML5**, **CSS3**, **JavaScript (WAAPI)**, **GSAP 3**, and **Anime.js / Framer Motion** with one-click CDN links. |
| **124-Skill Registry (`SKILL.md`)** | A built-in library of 124 one-click "expert rulebooks" (including 8 dedicated **Qwen 2.5 Coder** packs) that train the AI on best practices. |
| **Selected Skills Workspace Bar** *(Collapsed by Default)* | A clean `Skills (N)` button tucked neatly at the bottom-left that expands on click to show, add (`+ Qwen 2.5 Pack`), or remove skills for your active project. |
| **Docker (`node:20-alpine` Sandbox)** | Creates a sealed, virus-proof "safe testing room" for each project with strict memory (`2 GB` RAM) and processor (`2 CPU`) limits. |
| **FastAPI & Python (`3.11+`)** | The high-speed backstage coordinator that manages the Local AI Engine, project files, automatic backups, and safety checks. |
| **WebSockets (Real-Time Streaming)** | A live two-way communication line that streams every AI step, code change, and terminal message to your screen the millisecond it happens. |
| **Atomic Diff & Backup Engine** | Automatically saves a hidden backup copy (`.studio_backups`) before every edit and applies surgical changes so you can undo mistakes instantly. |
| **Next.js 15, React 18 & Tailwind CSS** | Powers the fast, sleek VibeForge studio interface along with its 4 built-in Darker and Lighter visual themes. |
| **Microsoft Monaco Editor** | Embeds the industry-standard VS Code editor with a "Track Changes" (**Diff View**) mode to inspect or manually edit any line of code. |
| **Git CLI & ZIP Archive Engine** | Packages your finished application into a one-click `.ZIP` download or publishes it directly to a GitHub repository for your engineering team. |
